# Documentation

How to install Why Can't I Sleep?, set it up on a server, change it with data packs, and build on it from another mod.
For how it plays, see the [Wiki](../wiki/index.md).

<div class="grid cards" markdown>

-   **Installing**

    ---

    [Installation](installation.md) in single player and on a server, the optional mods, and
    [Compatibility](compatibility.md) with the rest of your modpack.

-   **Server owners**

    ---

    Every option in [Configuration](server/configuration.md), with its default, and the mod's
    [commands](server/commands.md).

-   **Data packs**

    ---

    Change what blocks sleep and what hiding ignores with [tags](datapacks/index.md), and add your own
    [sleep modifiers](datapacks/sleep-modifiers.md), [sleep effects](datapacks/sleep-effects.md) and
    [hiding spots](datapacks/hiding-spots.md), no code needed.

-   **Mod developers**

    ---

    Read a player's sleep, start and stop hiding, add hiding spots and listen to [events](developers/events.md) with
    the [API](developers/index.md), and write data with [data generation](developers/datagen.md).

</div>

!!! note "Versions"
    The configuration, data pack formats and API are the same on every version the mod runs on: 26.1 to 26.3 (Fabric,
    NeoForge), 1.21.1 (Fabric, NeoForge, Forge) and 1.20.1 (Fabric, Forge). Where a detail differs, the page says so;
    pick your version in the header to see only what applies to you.
