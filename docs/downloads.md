# Downloads

Download Why Can't I Sleep? only from its official pages:

[Modrinth](https://modrinth.com/mod/why-cant-i-sleep){ .md-button .md-button--primary }
[CurseForge](https://www.curseforge.com/minecraft/mc-mods/why-cant-i-sleep){ .md-button .md-button--primary }

It needs [CoolCatLib](https://modrinth.com/mod/coolcatlib) and [Folios](https://modrinth.com/mod/folios), and
[Fabric API](https://modrinth.com/mod/fabric-api) on Fabric. [Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat)
is optional.

| Minecraft | Loaders |
| --- | --- |
| 26.1 – 26.3 | Fabric, NeoForge |
| 1.21.1 | Fabric, NeoForge, Forge |
| 1.20.1 | Fabric, Forge |

Then follow [Getting started](wiki/getting-started.md). Questions and bug reports are welcome on
[Discord](https://discord.gg/ZapGEPqm2V).
